One number, digits only: my honest count of open browser tabs — **143**.

143 is surprising (far higher than most people would guess), believable (a real tab hoarder can have 143 tabs open right now), and oddly specific, so it reads as a real counted number from someone who opens tabs faster than they close them.

Run `node main.ts` and it writes `143` to `/output/entry.txt` — exactly 3 bytes, no trailing newline.
